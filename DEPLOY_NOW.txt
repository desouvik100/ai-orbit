================================================================================
        AI ORBIT COMPANIES - VERCEL DEPLOYMENT INSTRUCTIONS
================================================================================

Your backend is ready to deploy! Follow these steps EXACTLY:

================================================================================
OPTION 1: DEPLOY VIA VERCEL DASHBOARD (EASIEST - RECOMMENDED)
================================================================================

1. PUSH TO GITHUB
   -------------
   If you haven't already:
   
   a. Create a new repository on GitHub:
      https://github.com/new
      Name it: ai-orbit-companies
   
   b. Run these commands in your terminal:
      
      git remote add origin https://github.com/YOUR_USERNAME/ai-orbit-companies.git
      git branch -M main
      git push -u origin main

2. DEPLOY TO VERCEL
   ----------------
   a. Go to: https://vercel.com/new
   
   b. Click "Import Git Repository"
   
   c. Connect your GitHub account if needed
   
   d. Select the "ai-orbit-companies" repository
   
   e. Click "Import"
   
   f. Keep all default settings (Next.js auto-detected)
   
   g. Click "Deploy"
   
   ⚠️  First deployment may fail - this is OK! We'll fix it in the next step.

3. SET UP DATABASE
   ---------------
   Choose ONE option:
   
   OPTION A - Vercel Postgres (Easiest):
   
   a. In Vercel dashboard, click "Storage" tab
   b. Click "Create Database"
   c. Select "Postgres"
   d. Name it: ai-orbit-db
   e. Select same region as your app
   f. Click "Create"
   g. Click "Connect" to link to your project
   
   OPTION B - Supabase (Free):
   
   a. Go to https://supabase.com
   b. Create new project
   c. Wait for database setup (~2 min)
   d. Go to Settings → Database
   e. Copy "Connection string"
   f. Replace [YOUR-PASSWORD] with your password
   g. In Vercel: Settings → Environment Variables
   h. Add DATABASE_URL with the connection string

4. INITIALIZE DATABASE (RUN LOCALLY)
   ----------------------------------
   Open your terminal and run:
   
   npm install -g vercel
   vercel login
   vercel link
   vercel env pull .env.local
   npm run db:push
   npm run db:seed
   
   You should see: "✅ Seed completed successfully!"

5. REDEPLOY
   --------
   a. Go to Vercel dashboard → Your Project
   b. Click "Deployments" tab
   c. Click the three dots "..." on latest deployment
   d. Click "Redeploy"
   e. Wait for deployment to complete

6. TEST YOUR API
   -------------
   Open in browser or use curl:
   
   https://YOUR-PROJECT-NAME.vercel.app/api/companies
   https://YOUR-PROJECT-NAME.vercel.app/api/companies/openai
